# Image attribution

All photography in this directory is of the **actual Guwahati → Tawang corridor** the demo runs
on — NH-13 through West Kameng and Tawang districts, Arunachal Pradesh — not generic mountain
stock. Every file is used under a Creative Commons licence that permits commercial and
derivative use with attribution.

Attribution is rendered in the UI wherever an image is displayed at size (login page, Command
Center brand card) via the `credit` prop on `HeroBand` / `ImagePanel`. Do not remove it.

## Notes

- Files are the 1920px-wide Commons renderings, retained at that size so the hero band and the
  login split panel stay sharp on a HiDPI projector. Total ~2.6 MB.
- `ner-corridor-road.jpg` and `ner-mountain-road.jpg` both show a loaded supply vehicle passing
  under an overhanging rock face on the Sela Pass approach — the exact hazard class the risk
  model scores. That is why they were chosen over a generic landscape.
- CC BY-SA (`ner-valley.jpg`) carries a share-alike obligation on *derivative works of the
  image*. It is used unmodified as a background, which does not trigger it, but do not
  composite it into a new graphic without checking.
